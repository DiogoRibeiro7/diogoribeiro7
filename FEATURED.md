# Featured Projects

A short list for reviewers who want the strongest cross-section of the portfolio without browsing the full catalogue. The first six mirror the profile pins; the second six broaden the evidence across research software, statistical methods, scientific ML, optimisation and quantitative research. Maturity is explicit so finished software, production-style systems, empirical studies and active research programmes are not presented as the same thing.

## Profile pins

| Project | Area | Maturity | Why inspect it |
| :-- | :-- | :-- | :-- |
| **[feedback-intelligence-agent](https://github.com/DiogoRibeiro7/feedback-intelligence-agent)** | Production AI | production-style system | Production-shaped RAG with FastAPI, retrieval evaluation, guardrails, observability and CI. |
| **[ragops-lab](https://github.com/DiogoRibeiro7/ragops-lab)** | RAG / LLMOps | research software | Evaluation-first RAG infrastructure with hybrid retrieval, claim-level grounding checks, tracing and regression coverage. |
| **[clinic-forecasting-platform](https://github.com/DiogoRibeiro7/clinic-forecasting-platform)** | Forecasting & MLOps | production-style system | Healthcare demand forecasting with rolling-origin evaluation, conformal intervals, serving, monitoring and staffing decisions. |
| **[transaction-risk-lakehouse](https://github.com/DiogoRibeiro7/transaction-risk-lakehouse)** | Data engineering | production-style system | PySpark lakehouse for transaction risk, behavioural features, temporal validation, scoring and monitoring. |
| **[pinn](https://github.com/DiogoRibeiro7/pinn)** | Scientific computing | research software | PyTorch PINN framework for forward and inverse PDE problems with exact-solution benchmarks and reproducible error analysis. |
| **[bmssp](https://github.com/DiogoRibeiro7/bmssp)** | Algorithms | research software | Typed deterministic single-source shortest paths using a BMSSP-style divide-and-conquer design. |
